# Промежуточная версия — 18 ноября 2026

Ветка: `preview/lead-critical-passes-20261118`.

Это рабочий срез для установки и обратной связи. Финальная приёмка большой задачи по фреймворку ещё не получена; работа над транспортом доказательств отложена. `main` сохраняет предыдущую версию.

## Что входит

- Дополнительные проходы (один при риске LOW/MEDIUM, три при HIGH) исходным главным ботом для новых нетривиальных корневых задач: сверка первоначальных требований и утверждённых уточнений, поиск пробелов и проверка исправлений.
- Отдельные независимые acceptance, code review и оценка достаточности тестов. Проходы главного бота их не заменяют.
- Сохранение замечаний при смене утверждённых требований; закрытие унаследованного замечания требует явного указания его происхождения и доказательств.
- Сохранение уже полученного ответа при сбое, включая ответ на устаревшее задание: такой ответ сохраняется без ошибочного зачёта или повторного запуска модели.
- Хешированные исторические исходники и результаты проверок; одинаковые данные переиспользуются, подходящие старые исходники могут передаваться через проверяемые изменения строк. Исходные архивы сохраняются.
- Согласованные инструкции Codex, Claude Code и Copilot. Ранее сохранённые задачи без нового режима не включаются в него автоматически.

## Проверенное состояние

До публикации этого среза полный локальный набор выполнил **1519 тестов без пропусков**, включая **105 регрессий нового режима**. Хеши runtime, тестов и политики проверяются перед публикацией; эти исходники после полного запуска не менялись. Свежие дополнительные проверки среза фиксируются в сообщении о публикации. CI запускается отдельно на опубликованном коммите.

Реальная цепочка Codex проверяла замечания, исправления, независимые роли и восстановление после аварийного завершения. Отдельный независимый потребитель восстановил и сверил 206 исторических ссылок с архивами и проверил закрытие исходного замечания по его действительным доказательствам. Эти проверки не означают, что вся доработка получила итоговый `APPROVED`.

## Известные ограничения

Очень большой пакет исходников, уточнений и истории может превысить предел одного запроса CLI. В проверенном Codex CLI наблюдался предел **1 048 576 символов**; отдельный предел размера пакета фреймворка тоже сохраняется. Именно это блокирует итоговую приёмку накопленной истории самого фреймворка. При нехватке обязательных доказательств gate должен остановить завершение, а не объявить `PASS`.

Дозапрос источников небольшими порциями ещё не реализован. Экспериментальная локальная упаковка, применявшаяся при исследовании, в устанавливаемую версию не включена. Не отключайте проверки и не удаляйте историю ради прохождения gate; ограничьте задачу относящейся к ней областью и сохраните контекст при блокировке.

Живые сеансы проверены на Codex и Claude (задача bugfix-evidence-20261119: adequacy, AC и ревью на Claude CLI). Copilot прошёл структурные и протокольные проверки; живые сеансы Copilot не проверялись. Локальная аттестация не защищает от вредоносного процесса с теми же правами ОС.

## Установка и обновление

Используйте команду клонирования этой ветки и обычный установщик из [README](../README.md#подключить-к-существующему-проекту). Локальные настройки, память и журнал проекта сохраняются штатным механизмом обновления; приватные данные не входят в этот Git-срез.
