## Дополнение: исследование перед вопросами владельцу

Обновлены существующие discovery/intake/communication/context skills и собственные локальные Codex-копии. Перед материальным вопросом агент выбирает релевантные авторизованные источники: код/контракты, причины в Git/PR/ADR, ограниченные логи/трейсы, схему или read-only данные и связанные сервисы. Не требуется обходить все источники. Запрет поиска аналогов сохраняется.

По умолчанию на нерешённый вопрос/группу — один целевой проход и максимум один полезный дополнительный. Усилия общие для ведущего агента, делегатов и возобновлений; остановка также наступает раньше при достаточном ответе, отсутствии новых зацепок или решении только владельца. Исчерпание лимита и отказ доступа не доказывают отсутствие ответа вообще. Безопасный default должен опираться на правила, контракт или делегирование; меньший риск сам по себе не разрешает новую бизнес-политику.

Оставшийся значимый вопрос сначала получает владелец: проверенные факты, рекомендация, причина и требуемое решение. Вопрос команде отправляется после согласования конкретного текста и адресата; уже такое согласование не запрашивается повторно. Независимая одобренная работа продолжается.

Проверено: **17 тестов установки**, пакеты для трёх ботов, 28 локальных owned-файлов, ссылки и metadata; пять контрольных и пять обновлённых Codex-сессий по восемь сценариев, затем пять финальных сессий по пять уточнённых сценариев. Это симуляции решений, не реальные запросы к production/GitHub/БД. Контроли уже были в основном корректны; улучшение частоты ошибок не измерено. Исходная неоднозначность default и квалифицированный прогон с ошибкой описания числа сценариев сохранены.

Финальная отдельная приёмка: **5/5 PASS**, substantive review без P0–P3, свежий gate **APPROVED**, задача **COMPLETED**. Первый blocked gate сохранён; дополнены actual source-preservation inventory, исходники установщика/тестов и реальные записи SQLite knowledge/checkpoint/journal с чтением после повторного открытия. Runtime, тесты и установщик по Git не менялись; полный runtime-suite заново не запускался. Это инструкции скиллов без нового MCP, зависимости или программного счётчика исследования. Живое поведение Claude/Copilot не проверялось по решению пользователя.

В контексте сохранены проверенная область, неизвестные, версия источника, причина остановки, общие затраты и следующий шаг. Блокеров в этом изменении нет.
