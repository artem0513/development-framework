Explicit CLI `--home` wins, then a selected project's local config, then ASE_HOME, then the legacy platform default. A selected repo/path wins over unrelated cwd context. Within a local project, normal calls from subdirectories find the nearest config. Local launchers select their own project even when called from another directory, using relative runtime paths without modifying the parent environment.
