# Source completeness for document-dependent tasks

Use only when requirements depend on documents, discussions, recordings or linked evidence. The user/project supplies relevant repositories, sources, scope and access permissions later. Do not discover accounts, collect broadly or enable schedules from this template.

Read `coverage TASK` for the source sequence (0 for a new source). A stale source sequence must be reloaded and reconciled, never overwritten. Maintain each source with `source-record TASK --expected-sequence N --file PATH` and inspect `coverage TASK`. Use a stable source id, credential-free locator, immutable revision/hash, positive extent and inclusive 1-based read ranges with unit set to lines, cues or bytes. Read sequential bounded chunks with overlap; inspect truncation and preserve exact gaps/next ranges. A search hit, inventory, sample or generated summary is not a complete read. Status separates discovered, acquired, fully_read, analyzed and blocked. Fully_read needs complete range coverage; analyzed additionally needs reconciled findings and no unresolved gaps. A changed revision starts fresh coverage instead of carrying old ranges forward.

Follow required references within authorized scope. Record decisions, actions, dependencies, contradictions and unresolved questions with original source plus line/timestamp; distinguish explicit assignment from inference. Reconcile duplicate parts by identity and revision, not title alone. Do not treat unavailable evidence as absence of obligations.

An empty ledger means unconfigured. Analyzed sources do not establish that undiscovered sources do not exist: the agent must review the agreed inventory and required references. Concrete blocked sources permit a clearly bounded partial report, never overall completeness. The ledger is declared analysis evidence, not a semantic verifier or permission grant; independent AC verification and command-backed gate remain required. Where completeness is a mandatory AC, define observable checks in the task contract. Do not hide an unresolved source requirement in an optional ledger.
